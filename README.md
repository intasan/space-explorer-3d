# Space Explorer 3D

Interactive 3D solar-system presentation.

## Features
- Sun
- Venus
- Earth
- Saturn
- Self rotation for each object
- No orbital animation
- Interactive 3D visualization

## Tech
Three.js, JavaScript, 3D Web

## Analysis Focus
ตัวอย่างการแปลง UX requirement ให้เป็น technical requirement และ interactive presentation.
